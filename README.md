# 深圳大学选课助手（浏览器插件版）

> 本插件改造自 [Lewin671/YourLesson](https://github.com/Lewin671/YourLesson)：原项目是针对深大选课系统的 Python 命令行抢课脚本，本插件把它的手动配置（复制 Cookie/token/学号）和命令行抢课流程，改造成了登录后自动捕获配置、网页面板一键抢课的 Chrome / Edge 浏览器插件，感谢原作者。

把原 Python 抢课脚本改造成 **Chrome / Edge 浏览器插件（Manifest V3）**。安装后登录选课网站即可自动完成配置，把课程数据导入面板勾选要抢的课，点一下「开始抢课」即可。

## 与原脚本的对应关系

| 原脚本 | 插件 |
| --- | --- |
| 手动 F12 复制 Cookie | 自动（同源请求自动携带登录 Cookie） |
| 手动复制 token | 自动捕获，或实时调用 `vcode.do` 获取 |
| 手动复制学号 / electiveBatchCode | 自动（拦截网站前端请求捕获），失败可手动填写 |
| 手动填 `setting.py` 的 cookie/token | 插件自动捕获并导出 `auto_config.json`，`download_data.py` 自动读取 |
| 运行 `download_data.py` 下载课程表 | 把生成的 `data/*.csv` 导入面板选课（不再实时拉取，避免"请求过快"被踢） |
| 编辑 `setting.py` 的 courses | 面板勾选 + 手动填 ID 兜底 |
| 运行 `main.py` 循环抢课 | 点「开始抢课」 |

## 安装

1. 打开 Chrome 或 Edge 地址栏输入 `chrome://extensions`（Edge 是 `edge://extensions`）
2. 右上角打开「开发者模式」
3. 点「加载已解压的扩展程序」，选择本目录（`extension/` 文件夹）

## 第一步：提前下载课程数据（Python 脚本）

课程列表是**离线导入**的，不再由插件实时拉取。提前用原 Python 脚本把课程下载成 CSV 文件，**不用手动填 `setting.py`**——插件会自动帮你把配置导出。

1. 确认电脑装了 Python 和依赖（`pip install requests`）
2. 登录选课网站后，在插件面板点**「导出配置」**，下载得到 `auto_config.json`
3. 把 `auto_config.json` 放到项目根目录（和 `download_data.py` 同级）
4. 选课开放前（能看到课程、但还不能提交的阶段），在项目根目录运行：

   ```bash
   python download_data.py
   ```

5. 脚本会读 `auto_config.json` 自动配置（学号/批次码/cookie/token，校外 webvpn 的地址也会带上），生成 `data/` 文件夹下的 7 个 CSV（本班课程 / 方案内课程 / 方案外课程 / 校公选课 / 体育课程 / 辅修课程 / 慕课），每个文件按类型命名，文件名里带类型中文名即可被插件识别。

> 插件对 CSV 是**按文件名**归类到对应课程类型的，别改掉中文文件名。
>
> 若不想用「导出配置」，仍可按原 README 手动填 `setting.py`（学号、electiveBatchCode、cookie、token），效果一样。

## 第二步：使用插件

1. 打开并登录选课网站：
   - 校园网：<http://bkxk.szu.edu.cn/>
   - 校外（webvpn）：<https://bkxk.webvpn.szu.edu.cn/>
   - 两个入口都支持，插件会自动识别当前页面域名并跟随请求。
2. 登录后**点进任意一个课程分类**（比如「本班课程」），插件会在后台自动捕获学号和批次码
3. 点浏览器右上角的插件图标打开面板
   - 顶部显示「已连接选课网站」「学号 xxx · 批次已配置」即表示自动配置成功
   - 若未自动捕获，可在「手动配置」里填写学号与 electiveBatchCode（获取方式见原 README 的 F12 说明）
4. **导入课程数据**：点「导入 CSV」，选中 `data/` 文件夹里的 CSV 文件（可多选）。导入后课程列表会出现在下方，按类型页签/下拉切换
5. 课程太多、面板太小不好选？点面板顶部的**「打开全页选课面板」**，会在新标签页打开完整的选课页面：
   - 上方课程类型页签（本班/方案内/方案外/校公选/体育/辅修/慕课）+ 搜索框
   - 「仅看有余量」「隐藏已选」两个筛选开关，几百上千条课程也能快速过滤
   - 「刷新课表」按当前页签类型实时重新拉取课程数据（余量/已选/冲突以系统为准），比「拉取全部」快得多；每行课程还有「立即选课」按钮，点一下直接提交一次志愿，不用走整轮抢课
   - 课程数据**两边共用**同一份已导入的数据，在全页面板里同样点「导入 CSV」或直接把 CSV 文件**拖进页面**即可
   - 右侧为已选课程（优先级顺序，可 ↑↓ 调整）、手动添加、抢课控制与日志
   - 全页面板和插件面板共用同一份「已选课程」数据，两边改动实时同步
6. 选课方式二选一：
   - 在面板里勾选课程（可搜索过滤）
   - 或手动填课程 ID 添加（兜底，F12 获取方式见原 README）
7. 设置间隔延迟（默认 400ms，建议不低于 400）
8. 到抢课时间点「开始抢课」即可；日志实时显示「成功 / 满员 / 提示」

## 常见问题

- **插件没反应 / 面板一直显示「未打开选课网站」**：确认当前标签页就是上面的选课网站地址；如果页面是在安装或更新插件之前就打开的，**刷新一下页面**即可（内容脚本需要注入）。
- **改了代码不生效**：在 `chrome://extensions` 里点该插件的「重新加载」，然后刷新选课网站页面。
- **面板显示「未捕获学号/批次码」**：登录后在选课网站里点进任一课程分类（如「本班课程」），插件会自动捕获；若仍失败，可在面板「手动配置」里填写学号与 electiveBatchCode（F12 获取方式见原 README）。
- **导入 CSV 后课程列表是空的**：确认导入的是 `download_data.py` 生成的文件、且文件名带类型中文名（本班课程 / 方案内课程 等）；换个类型页签看看，一个 CSV 只归到一个类型。
- **选课列表会不会过期？** 会。抢课开放后余量/容量会变化，CSV 里的数据只是用来勾选课程，**提交抢课时走的是实时接口**，是否满员以抢课日志返回为准。全页面板可随时点「刷新课表」按当前类型实时重新拉取。
- **「刷新课表」和「拉取全部」有什么区别？** 「刷新课表」只重新拉取**当前页签类型**的课程（几秒到几十秒）；「拉取全部」把 7 个类型全部翻页拉一遍（耗时较长）。
- **拉取成功了但列表是空的？** 数据其实在——默认勾选的「仅看有余量」会把满员课程全藏起来（选课未开放或全部抢完时就是 0 门显示）。空态提示会写明「共 N 门、满员/已选/冲突多少门」，点「取消筛选，显示全部」即可查看。
- **「立即选课」没反应/报「抢课进行中」？** 抢课循环运行期间不允许手动提交志愿，先点「停止」再手动选；会话过期时会提示重新登录选课系统。

## 说明

- 抢课期间请**保持选课网站标签页打开**（关闭或跳转页面会中断抢课）。
- 抢课逻辑与原脚本一致：按优先级顺序提交，**抢到第一个就停止**。
- 最终能否抢到取决于选课开放时段与课程余量，非开放时段会返回「该课程超过课容量」等提示，可用于验证请求链路是否通顺。

```

├── manifest.json
├── background.js      # 自动捕获学号/批次码/token/课程标签页
├── common.js          # 共享工具：CSV 解析与导入（popup 与全页面板共用）
├── content.js         # 同源请求核心（抢课/查结果/取 token）
├── select.html        # 全页选课面板（新标签页打开，课程多时用）
├── select.css
├── select.js
├── popup/
│   ├── popup.html
│   ├── popup.css
│   └── popup.js
└── icons/
```
